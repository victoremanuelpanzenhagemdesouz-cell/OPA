# OPA — versão HTML, CSS e JavaScript

O app foi convertido para arquivos estáticos:

- `index.html`: estrutura da página
- `styles.css`: identidade visual e responsividade
- `app.js`: navegação e interações
- `assets/opa-logo.jpg`: logo oficial

Para abrir no VS Code, clique em `index.html` com o botão direito e use **Open with Live Server**.

O projeto usa a biblioteca de ícones [Lucide](https://lucide.dev/) via CDN.
